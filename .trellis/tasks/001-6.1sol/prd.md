# 001-6.1sol 需求与验收

## 目标

HDEG 完成转录及翻译前数据生成，宿主 Agent 中的 `hz-rj-translate` 仅接续翻译。新增 `app.prepare_only=false`；开启后不调用字幕翻译，关闭时现有行为不变。

## 已确认的范围

- 用户明确要求同时改造 HDEG 与 Skill，并批准独立准备模式方案。
- 用户选择“两套保真资料”：original 与 normalized；为确保保真，后者只做空白/格式调整，所有非空白文字、角色标识、既定译名、年龄、身份、关系、同意等事实不变。
- 准备数据包括台本、世界观、角色、有效术语、alias、规范整理版、对齐、有效原文/时间轴、固定分块、静态翻译提示及可选润色模板。
- alias 现状仅加载、无自动生成；未提供输出 `[]` 和缺省说明，不假造新功能。
- 有 `A.lrc` 默认跳过；有 JA 无目标直接准备；缺两者才转录。Skill不改源，整轨成功才提交目标。

## 现有事实与设计依据

- 新分流位于 `pipeline/orchestrator.py:3886` 后、旧多根和无主key早退前；只在开启时进入 `pipeline/translation_prepare.py`。
- 原世界观生成的主key检查、旧脱敏替换风险事实及旧缓存不作为新模式依据；新模块按实际用途合并API配置，使用独立保真规则。
- 台本/术语/世界观提示构造仍含读音聚类和对齐，不是单纯格式化；全部留在HDEG，Skill不导入引擎/API/预处理模块。
- 元数据READY单文件原子发布不等于多文件事务；消费者校验全部资产摘要、源摘要和路径。

## 需求与验收

| ID | 要求 | 验收观察 |
| --- | --- | --- |
| R1 | prepare_only缺省/false保持旧路径 | 配置默认false，旧流式/批式及原相关测试继续通过 |
| R2 | 开启后只转录准备、不字幕翻译 | 单/多根、stream/all_at_once均独立分流；翻译/润色/重试/峰谷调用陷阱不触发 |
| R3 | 精确输出范围与跨根去重 | 子目录不会扩大至兄弟轨，同作品多根只准备一组；未生成JA不报准备完成 |
| R4 | HDEG生成全部上下文与分块资产 | 两版context、术语、alias、台本/对齐、源/时间轴/chunk/prompt齐全并可消费 |
| R5 | 两版保真，不隐藏事实 | 字段结构、角色标识、固定译名及显式事实变化被拦截；旧脱敏缓存不被默认为新版 |
| R6 | 合法缺省与失败区分 | 无alias/确认无台本/FreeTalk可显式缺省；坏缓存、API拒绝/截断/解析失败不伪装空值 |
| R7 | 准备包可靠发布与复用 | PREPARING/FAILED不可消费；READY前验证所有资产，源/输入/规则变化使缓存失效 |
| R8 | Skill只消费不预处理 | CLI仅scan/open-track/submit-chunk/submit-polish/fail-track；不读全局API配置/不调用引擎、对齐或脱敏 |
| R9 | 消费结果保持源与时间轴 | 两块按ID回绑、源不变、包不变、缺ID/重复/类型错误拒绝 |
| R10 | 终态和目标保护 | COMMITTED/FAILED_STOPPED拒绝重复，源变化和他方target阻止覆盖；force仅显式且目标摘要未变 |
| R11 | 模型拒答止损 | 无四级/自动换上下文/换子代理重试；明确拒答停止并记录 |
| R12 | 交接真正贯通 | 真实生产函数导出→真实消费CLI→两块及润色→原时间轴目标，固定假模型离线验收 |

## 配置和费用

准备仍可能调用HDEG现有台本接口、api.worldview和api.desensitize；只有字幕翻译交给Agent订阅。没有免费/离线/绕过内容限制保证。真实API与GPU验证需后续授权，本轮仅自建中性夹具和假响应。

## 不在范围

- 改原模式共享APIClient/翻译引擎、旧四级规则，或重构所有历史PDF/缓存算法。
- 新增自动alias生成、复杂resume、自动插件安装、宿主凭据代理或安全过滤绕过。
- 改本地真实凭据、运行真实作品/API/GPU、构建打包、Git提交/推送。
